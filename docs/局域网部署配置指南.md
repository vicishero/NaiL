## 配置文件修改记录

### 1. `admin/.env`

```env
VITE_BASE_PATH = http://192.168.30.44
```

**说明**：将前端 API 请求代理地址从 `127.0.0.1` 改为局域网 IP，确保局域网内其他设备能正确访问后端接口。

### 2. `admin/vite.config.js`

```javascript
server: {
  host: '0.0.0.0',           // 监听所有网络接口
  open: true,
  port: Number(env.VITE_CLI_PORT),
  hmr: {
    host: '192.168.30.44',   // 热更新主机配置
    port: Number(env.VITE_CLI_PORT)
  },
  proxy: {
    [env.VITE_BASE_API]: {
      target: `${env.VITE_BASE_PATH}:${env.VITE_SERVER_PORT}/`,
      changeOrigin: true,
    },
    '/plugin': {
      target: `${env.VITE_BASE_PATH}:${env.VITE_SERVER_PORT}/`,
      changeOrigin: true,
      rewrite: (path) => path.replace(new RegExp('^/plugin'), '')
    }
  }
},
```

**说明**：
- `host: '0.0.0.0'` - 允许来自任何 IP 的访问
- `hmr.host` - 配置 Vite 热更新服务的主机地址，解决局域网访问时热更新失效问题
- `/plugin` 代理 - 使用环境变量代替硬编码地址

## 服务启动命令

### 后端服务

```bash
# 编译
go build -tags "embed" -o paopao

# 启动
./paopao serve > logs/backend.log 2>&1 &
```

### 用户端 Web 前端

```bash
cd web
npm run dev > ../logs/web.log 2>&1 &
```

### 管理后台 Web 前端

```bash
cd admin
npm run dev > ../logs/admin.log 2>&1 &
```

### 一键重启所有服务

```bash
# 停止所有服务
pkill -f "paopao serve"
pkill -f "vite"

# 重新编译并启动后端
go build -tags "embed" -o paopao
./paopao serve > logs/backend.log 2>&1 &

# 启动前端
cd web && npm run dev > ../logs/web.log 2>&1 &
cd ../admin && npm run dev > ../logs/admin.log 2>&1 &
```

## 常见问题

### 1. 验证码接口 404

**现象**：访问管理后台时，`/api/v1/base/captcha` 返回 404

**原因**：后端二进制文件不是最新版本，缺少 GVA 管理后台路由

**解决**：重新编译并启动后端服务
```bash
pkill -f "paopao serve"
go build -tags "embed" -o paopao
./paopao serve > logs/backend.log 2>&1 &
```

### 2. 局域网访问页面空白或热更新失效

**现象**：在其他设备访问前端页面空白，或浏览器控制台显示 WebSocket 连接错误

**原因**：Vite 热更新 (HMR) 没有正确配置局域网 IP

**解决**：确保 `admin/vite.config.js` 中配置了正确的 `hmr.host`

### 3. 前端请求被拒绝

**现象**：前端 API 请求失败，浏览器显示连接被拒绝

**原因**：后端服务未启动，或者 `.env` 中的 IP 地址配置错误

**解决**：
1. 检查后端服务是否运行：`ps aux | grep paopao`
2. 确认 `admin/.env` 中的 `VITE_BASE_PATH` 是正确的局域网 IP
3. 确认防火墙没有阻止相关端口
